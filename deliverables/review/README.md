# Комплект для загрузки на ревью

Загружать следующие файлы в Markdown:

1. `PROJECT_DESCRIPTION_FINAL.md` — «Описание проекта — финальная версия».
2. `product/01_user_hypothesis_and_value.md`.
3. `product/02_mvp_scenario_and_decisions.md`.
4. `product/03_validation_risks_and_pilot.md`.

Последние три файла — компактный комплект «Продуктовые материалы — финальная версия». Они не дублируют технические артефакты: подтверждающие результаты лежат в `results/experiments/20260905_wave0_temporal_v3_baseline/`.

Не загружать вместе с этими материалами: `.venv/`, `tmp/`, `fx-push-demo/node_modules/`, `fx-push-demo/dist/`, `fx-push-demo/verification/`, исходники из `scripts/` и `fx-push-demo/src/`, тесты, конфиги, сырые данные и полные CSV/архивы экспериментов. Они нужны для разработки и воспроизводимости репозитория, но не для проверки двух обязательных работ.

Перед загрузкой проверьте только написание ФИО в таблице команды: оно восстановлено из Git-истории и при необходимости должно быть заменено на полные имена участников.
