# CIS Trading

CIS Trading — исследовательский ML-прототип, который подсказывает подходящий момент для перевода рублей в валюты стран СНГ.

Пользователь видит простой сигнал **«выгодно сейчас»**. Сервис не пытается угадать абсолютный минимум курса: он оценивает, даст ли ожидание в ближайшие три дня заметно более выгодный курс.

Поддерживаемые направления: RUB→TJS, RUB→UZS, RUB→KGS, RUB→AMD и RUB→KZT.

## Как работает решение

1. Загружаем исторические курсы ЦБ РФ.
2. Для каждой даты рассчитываем динамику курса и внешние рыночные факторы.
3. Random Forest оценивает, безопасно ли сделать перевод сегодня вместо ожидания до трёх дней.
4. Отдельный порог для каждого валютного направления превращает оценку модели в редкий сигнал.
5. После сигнала действует пауза четыре дня, чтобы не перегружать пользователя уведомлениями.

При обучении модель видит только данные, доступные на дату решения. Качество проверяется на следующих по времени годах, а пороги выбираются до тестового периода.

## Текущее лучшее решение

Выбран pooled Random Forest на основном продуктовом target `message_hit` с рыночными и валютными признаками. Это лучшая из сопоставимо проверенных конфигураций.

На исторической out-of-time проверке:

- **84,7%** сигналов не проиграли ожиданию более 0,5%;
- модель дала результат в **1,21 раза лучше** сопоставимого случайного расписания;
- средняя частота — около **0,43 сигнала в неделю** на валютное направление.

Целевой уровень превосходства 1,3 пока не достигнут, поэтому результат следует считать сильным прототипом, а не готовым доказательством продуктового эффекта.

## Какие продуктовые идеи проверили

| Продуктовая гипотеза | Как проверяли | Вывод |
|---|---|---|
| Более сложная модель точнее находит момент | Заменили Random Forest на CatBoost на тех же временных периодах | Не улучшила выбранное решение |
| Связь локальной валюты с долларом добавляет полезный контекст | Добавили implied-USD признаки | Устойчивого улучшения нет |
| Нужно искать локально привлекательный курс, а не только безопасный момент | Обучили модель на положении курса в окне вокруг даты | Находит красивые исторические точки, но хуже защищает от улучшения курса после сигнала |
| Фильтр привлекательности сделает редкие пуши надёжнее | Добавили причинный фильтр по прошлым 28 дням | Сигналы стали слишком редкими и не точнее |
| Более широкий подбор параметров Random Forest улучшит итог | Проверили девять сочетаний глубины и размера листа | Внутренняя ML-метрика выросла, но продуктовая OOT-оценка ухудшилась |
| Простые индикаторы или подтверждение несколькими днями надёжнее | Проверили rule-based индикаторы и slow confirmation | Текущую политику не улучшили |

Эти эксперименты сохранены как отрицательные результаты, чтобы не повторять те же ветки без новых данных или новой продуктовой идеи. [Краткая таблица альтернатив](results/alternative_solutions/README.md).

## Что уже готово

- воспроизводимая сборка датасета из исходных DBF;
- защита от использования будущих данных;
- walk-forward оценка по годам;
- подбор модели и порога только на validation;
- сопоставимый случайный baseline с тем же числом сигналов и cooldown;
- сохранение параметров и артефактов каждого запуска;
- unit-тесты критичных формул и signal policy.

## Ограничения

Исследование использует официальные курсы ЦБ РФ как рыночный proxy. Банковские комиссии, спреды и реальные курсы переводов пока не учтены. Также нет продуктовых event logs, поэтому влияние пушей на конверсию и доверие пользователей ещё не измерено.

## Быстрый старт

Требуется Python 3.14+ и [uv](https://docs.astral.sh/uv/).

```powershell
uv sync
uv run python -m unittest discover -s tests -v
uv run python scripts/build_dataset.py --help
uv run python scripts/run_experiment.py --help
```

Полный benchmark ресурсоёмкий и не нужен для знакомства с репозиторием. Готовые результаты находятся в `results/`.
