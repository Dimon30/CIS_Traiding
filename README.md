# CIS Trading

CIS Trading — ML-сервис, который подсказывает подходящий момент для перевода рублей в валюты стран СНГ.

Пользователь видит простой сигнал **«выгодно сейчас»**. Сервис оценивает, даст ли ожидание в ближайшие три дня заметно более выгодный курс.

Поддерживаемые направления: RUB→TJS, RUB→UZS, RUB→KGS, RUB→AMD и RUB→KZT.

## Как работает решение

1. Загружаем исторические курсы ЦБ РФ.
2. Для каждой даты рассчитываем динамику курса и внешние рыночные факторы.
3. Random Forest оценивает, безопасно ли сделать перевод сегодня вместо ожидания до трёх дней.
4. Отдельный порог для каждого валютного направления превращает оценку модели в редкий сигнал.
5. После сигнала действует пауза три дня, чтобы не перегружать пользователя уведомлениями.

При обучении модель видит только данные, доступные на дату решения. Качество проверяется на следующих по времени годах, а пороги выбираются до тестового периода.

## Текущее лучшее решение

Выбран pooled Random Forest на основном продуктовом target `message_hit` с рыночными и валютными признаками. Это лучшая из сопоставимо проверенных конфигураций.

На исторической out-of-time проверке:

- **84,7%** сигналов соответствовали критерию выгодного момента;
- модель дала результат в **1,21 раза лучше** сопоставимого случайного расписания;
- средняя частота — около **0,43 сигнала в неделю** на валютное направление.

[Полный отчёт выбранного запуска](results/experiments/20260905_wave0_temporal_v3_baseline/RESULTS.md)

## Какие продуктовые идеи проверили

| Продуктовая гипотеза | Как проверяли | Вывод |
|---|---|---|
| Более сложная модель точнее находит момент | Заменили Random Forest на CatBoost на тех же временных периодах | Random Forest показал более сильный результат и остался основным |
| Связь локальной валюты с долларом добавляет полезный контекст | Добавили implied-USD признаки | Сохранён основной набор признаков как более устойчивый |
| Нужно искать локально привлекательный курс, а не только безопасный момент | Обучили модель на положении курса в окне вокруг даты | Сохранён `message_hit`, напрямую соответствующий обещанию уведомления |
| Фильтр привлекательности сделает редкие пуши надёжнее | Добавили причинный фильтр по прошлым 28 дням | Базовая policy сохранила лучший баланс частоты и качества |
| Более широкий подбор параметров Random Forest улучшит итог | Проверили девять сочетаний глубины и размера листа | Текущая конфигурация RF подтвердила преимущество на итоговой OOT-оценке |
| Простые индикаторы или подтверждение несколькими днями надёжнее | Проверили rule-based индикаторы и slow confirmation | Основная ML-policy показала более сильный результат |

Эксперименты сохранены как реестр завершённых проверок и оснований для выбора основной конфигурации. [Краткая таблица альтернатив](results/alternative_solutions/README.md).

## Что уже готово

- воспроизводимая сборка датасета из исходных DBF;
- защита от использования будущих данных;
- walk-forward оценка по годам;
- подбор модели и порога только на validation;
- сопоставимый случайный baseline с тем же числом сигналов и cooldown;
- сохранение параметров и артефактов каждого запуска;
- unit-тесты критичных формул и signal policy.

## Данные и развитие

Текущая оценка построена на открытых официальных курсах ЦБ РФ. Архитектура позволяет следующим этапом подключить банковские курсы, комиссии и продуктовые события для оценки клиентского эффекта.

## Быстрый старт

Требуется Python 3.14+ и [uv](https://docs.astral.sh/uv/).

```powershell
uv sync
uv run python -m unittest discover -s tests -v
uv run python scripts/build_dataset.py --help
uv run python scripts/run_experiment.py --help
```

Готовые результаты для знакомства с проектом находятся в `results/`; команды выше позволяют проверить окружение и основные точки входа.

Интерактивное демо запускается отдельно:

```powershell
cd fx-push-demo
npm install
npm run dev
```
