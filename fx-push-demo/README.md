# FX Push Demo

Интерактивный мобильный прототип сценария валютного сигнала для кейса CIS Trading.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который напечатает Vite (обычно `http://127.0.0.1:5173`).

## Данные календаря

Демо читает версионированный `public/model-signals.json`, который создаётся из
сохранённых OOT-предиктов experiment bundle:

```powershell
uv run python scripts/export_demo_signals.py `
  --run-dir results/experiments/<run_id> `
  --hypothesis-id <hypothesis_id> `
  --model <model> `
  --strategy <strategy> `
  --horizon-days 3 `
  --epsilon-bps 50
```

Команду выполнять из корня репозитория. Если в bundle значение selector
единственное, соответствующий аргумент можно не указывать; неоднозначный экспорт
завершится ошибкой, чтобы случайно не смешать несколько policies. После появления
новой модели достаточно повторить команду и пересобрать фронтенд. Подробнее о
контракте: [`DATA_CONTRACT.md`](DATA_CONTRACT.md).

## Проверка

При запущенном dev-сервере в отдельном терминале:

```bash
npm run build
npm run lint
npm run verify:ui
```

`verify:ui` проходит сценарий в локальном Chrome и сохраняет актуальные экраны в папку `verification`.

## Сценарий

1. Дождитесь появления уведомления.
2. Нажмите на него или потяните вправо.
3. Нажмите «Открыть».
4. После запуска откроется предзаполненный перевод.
5. Вернитесь на главный экран и выберите «За рубеж», чтобы открыть список стран.

На широком экране справа доступна демонстрационная панель: перезапуск сценария, смена текста пуша и быстрый переход на главный экран.

Календарь показывает три последовательных месяца, для которых в OOT-результате
достаточно модельных сигналов. В открытом по умолчанию месяце отмечены три даты,
в двух предыдущих — по две. Все отмеченные даты выбраны из настоящих OOT-сигналов.

Последний сигнал открывается как актуальный. При выборе более старой даты демо
показывает сценарий позднего входа: приложение сообщает, что курс уже обновился,
и предлагает проверить текущую сумму перед переводом. Курсы, тексты и суммы на
экранах перевода остаются демонстрационными.
