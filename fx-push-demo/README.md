# FX Push Demo

Интерактивный мобильный прототип сценария валютного сигнала CIS Trading.

## Запуск

```bash
npm install
npm run dev
```

Календарь показывает демонстрационное расписание: 2 и 19 сентября, 4, 9 и 22 октября, 6 и 18 ноября. Октябрь открыт по умолчанию. Для пушей используются сохранённые OOT-решения модели.

Плашка с объяснением показывается только при переходе из свежего пуша с пометкой «сейчас». Для пушей пяти или шести часов давности экран перевода остаётся обычным: историческое уведомление не подтверждает актуальность курса. Тексты объяснений в демо используют два сценария: сравнение со средним за месяц и улучшение курса четвёртый день подряд.

## Проверка

```bash
npm run build
npm run lint
npm run verify:ui
```

`verify:ui` проходит основной сценарий в Chrome и сохраняет скриншоты в `verification`.
