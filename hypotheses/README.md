# Hypothesis registry

Один TOML-файл описывает одну проверяемую гипотезу. Он фиксирует признаки, target, модели и критерии принятия до просмотра test-результатов.

Нумерация `H001...H007` относится к ML-ablation внутри репозитория и не заменяет
нумерацию продуктовых гипотез в исходном документе. Соответствие и итоговые
вердикты находятся в `results/hypothesis_study/HYPOTHESIS_REPORT.md`.

- `H001`: только динамика и положение курса;
- `H002`: факторы кейса (уровень, momentum, volatility, calendar);
- `H006`: H002 плюс первые/вторые производные и reversal;
- `H007`: H006 плюс point-in-time признаки USD/EUR.
- `H008`: controlled ablation способа объединения валют: отдельные модели,
  общая модель с/без признака коридора и общий/отдельные thresholds.

Поле `status` в TOML описывает готовность спецификации к запуску, а не итоговый
вердикт по данным. Актуальные выводы H001–H007 собраны в `CURRENT_STATE.md` и
`results/hypothesis_study/HYPOTHESIS_REPORT.md`.

Статусы спецификации:

- `draft` — формулировка обсуждается;
- `ready` — спецификация заморожена и готова к запуску;
- `running` — эксперимент выполняется;
- `accepted` — гипотеза подтверждена;
- `rejected` — гипотеза не подтверждена;
- `limited` — работает только в части условий;
- `inconclusive` — данных недостаточно.
